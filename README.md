# Wind-tunnel
3m long Eiffel wind tunnel design with a 3x3 array of drone motors. I am measuring lift drag and airspeed.


This gives a readout of the fans' RPM, battery voltage, lift and drag forces, and airspeed. The list of components that I have that I need the Pi to talk to is:

9x2077.5 drone motors(3x3 array)

3x 4in1 60A 6s ESC running AM32

3x 6s 1000mAh lipo batteries

2x Hx711 load cell sensors (1x1kg,1x100g)

1x 4525D airspeed probe
